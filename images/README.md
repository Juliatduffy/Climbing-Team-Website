## Maintenance

- Put new images in the folder that describes how the site will use them.
- Keep filenames descriptive and use the same capitalization in HTML, CSS, JavaScript, and JSON references.
- Prefer lowercase kebab-case filenames for new files, such as `spring-bouldering-trip.jpg`.
- Do not move `2024-25CollegiateCompetitorGuide.docx_files/unnamed.png`; it is an embedded asset belonging to the adjacent exported document.

## Known duplicate
